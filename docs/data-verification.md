# Exam data verification record

Reviewed: 2026-10-23. Content revision: 2026-10-23.

This review covers all 34 original records and adds JEE Main Paper 1 and JEE Advanced (36 records). It checks selected official evidence, not every eligibility exception, programme, college, placement or fee. No profile is marked fully verified. A review date means the profile was examined; only a field entry with a source URL records verification.

`cycleYear` identifies the explicitly published exam/admission cycle. CLAT/AILET/UCEED 2026 dates can fall in 2025. XAT/SLAT/SEED explicitly publish 2027 cycles. SNAP 2026 explicitly serves 2027-28 entry. CAT retains its named CAT 2026 cycle. Incomplete legacy profiles retain 2026; this does not imply an open window.

`active` describes the recorded examination/cycle, not an open application window. `merged` is scoped to AIIMS/JIPMER undergraduate MBBS routes through NEET-UG. `discontinued` applies to PES B.Tech PESSAT. `needs-review` flags unresolved core information or source availability. Unknown numeric counts are null. Scaled NMAT/MAT scores are not raw total marks.

Unsupported placements, seat totals, tuition estimates, rankings, blanket budgets and preparation guarantees were removed. College/programme lists remain incomplete and are marked where not checked. Source pages can change; original notices and later amendments take precedence. Legacy values remain recoverable in Git history.

## Maintenance rules

1. Read the cycle-specific notice and later amendments before replacing a value.
2. Attest only fields supported by accessible official evidence; retain source URL and actual checked date per field.
3. Leave uncertain values explicit. Do not infer next-year dates, treat a snippet as proof of a final extension, or stamp verification because a script ran.
4. Updater output is a proposal requiring review. Content revision and source-check dates are different.
5. Check levels and programmes separately: MBBS is not INI-CET; UPESEAT is not UPESDAT; NIFT programmes have different patterns.
6. Preserve IDs for saved selections; do not reassign a record to an unrelated examination.
